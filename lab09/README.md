# Лабораторная работа № 9. Сортировка выбором

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab09/task01.py
```

Целые числа вводятся одной строкой через пробел, ввод подтверждается Enter. Допускаются отрицательные числа и повторения. Пустой ввод соответствует пустому массиву.

Например, для ввода `5 1 4 2` результат — `[1, 2, 4, 5]`.
