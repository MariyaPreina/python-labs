# Лабораторная работа № 5. Одномерные массивы

## Как запустить

Для запуска программы необходимо открыть терминал в папке `python-labs` и выполнить команду:

```bash
python3 lab05/task01.py
```

Для запуска другой задачи необходимо указать соответствующий файл, например `task10.py`.

Данные вводятся после приглашений программы, ввод подтверждается нажатием Enter. Для дробных чисел используется точка: `2.5`. В задачах 4–10 массив вводится одной строкой через пробел; N определяется по количеству введённых элементов. В задачах 7 и 10 используются целые числа. Номера элементов в условии и результатах начинаются с 1.
