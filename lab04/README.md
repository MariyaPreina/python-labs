# Лабораторная работа № 4. Рекурсивные алгоритмы

## Как запустить

Для запуска программы необходимо открыть терминал в папке `python-labs` и выполнить команду:

```bash
python3 lab04/task01.py
```

Для запуска другой задачи необходимо указать соответствующий файл, например `task09.py`.

Данные вводятся после приглашений программы, ввод подтверждается нажатием Enter. Для дробных чисел используется точка: `2.5`. В задаче 5 элементы массива вводятся одной строкой через пробел в порядке возрастания (допускаются равные соседние элементы). В задачах 4 и 6 вводится строка текста.
