# Лабораторная работа № 1. Линейные алгоритмы

## Как запустить

Для запуска программы необходимо открыть терминал в папке `python-labs` и выполнить команду:

```bash
python3 lab01/task01.py
```

Для запуска другой задачи необходимо указать соответствующий файл, например `task10.py`.

Числа вводятся по одному после каждого приглашения. Ввод каждого числа подтверждается нажатием Enter. Для отделения дробной части используется точка: `2.5`, а не `2,5`.
