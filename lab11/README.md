# Лабораторная работа № 11. Обход дерева

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab11/task01.py
```

Введите целые числа для построения бинарного дерева поиска через пробел, например `50 30 20 40 70 60 80`. Затем введите искомое число, например `40`. Сторонние библиотеки не требуются.

Программа добавляет введённые значения в дерево, ищет указанное число и выполняет симметричный обход: левое поддерево → узел → правое поддерево. Для примера выше находится число 40 и выводятся числа `20, 30, 40, 50, 60, 70, 80`, в одной строке. Перед поиском показывается структура дерева: отступы обозначают глубину, подписи «Слева» и «Справа» — положение относительно родителя.

Повторяющиеся значения сохраняются в правом поддереве. Для пустого списка дерево остаётся `None`: поиск сообщает об отсутствии элемента, обход не выводит значений.
