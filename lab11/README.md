# Лабораторная работа № 11. Обход дерева

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab11/task01.py
```

Ввод с клавиатуры не требуется. Значения для построения бинарного дерева поиска задаются в списке `values`, искомое число — в `target`. Сторонние библиотеки не требуются.

Программа добавляет значения в дерево, ищет число 40 и выполняет симметричный обход: левое поддерево → узел → правое поддерево. Для примера выводятся числа `20, 30, 40, 50, 60, 70, 80`, каждое с новой строки.

Повторяющиеся значения сохраняются в правом поддереве. Для пустого списка дерево остаётся `None`: поиск сообщает об отсутствии элемента, обход не выводит значений.

## Версия на JavaScript

В `task01.js` приведены только алгоритмы для сравнения с Python: без ввода и автоматического запуска; обход выводит значения узлов.
