# Лабораторная работа № 6. Двумерные массивы

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab06/task01.py
```

Для другой задачи необходимо указать соответствующий файл, например `task10.py`.

После ввода размеров матрицы каждая строка вводится отдельно: числа разделяются пробелами, ввод подтверждается Enter. Дробная часть отделяется точкой. В задачах 1 и 10 вводится только M: матрица квадратная. В задаче 1 M нечётное; в задаче 8 оба размера чётные. В задаче 5 вводятся целые числа. В задаче 2 после матрицы вводится номер строки K, начиная с 1.
