# Лабораторные работы по алгоритмам на Python

## Как запустить

Необходимо открыть терминал в папке `python-labs` и выполнить команду, например:

```bash
python3 lab01/task01.py
```

Инструкции по вводу и перечень задач приведены в README каждой работы. Дополнительные пакеты не требуются.

## Версии на JavaScript

В работах 7–12 файлы `task01.js` содержат алгоритмы для сравнения с Python, без ввода данных и автоматического запуска.
