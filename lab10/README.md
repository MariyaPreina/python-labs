# Лабораторная работа № 10. Бинарный поиск

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab10/task01.py
```

В первой строке вводятся целые числа через пробел **по возрастанию** (равные соседние значения допускаются). Во второй строке вводится искомое целое число. Ввод подтверждается Enter. Массив должен быть отсортирован заранее: программа не сортирует его и не проверяет порядок.

Результат — индекс с нуля либо −1, если числа нет. При повторениях возвращается индекс одного из совпадений, не обязательно первого. Пустая первая строка задаёт пустой массив.

Например, для массива `1 3 5 7 9` и искомого числа `7` результат — индекс `3`.

## Версия на JavaScript

В `task01.js` приведены только алгоритмы для сравнения с Python: без ввода, вывода и автоматического запуска.
