# Лабораторная работа № 12. Работа с очередью

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab12/task01.py
```

Введите целые числа через пробел, например `5 10 15`. Программа добавит их в очередь в порядке ввода и продемонстрирует операции с ней.

Используется `collections.deque` из стандартной библиотеки Python; установка дополнительных пакетов не требуется. Для примера `5 10 15` извлекается число 5, в начале остаётся 10, размер равен 2. Затем введите число для проверки наличия среди оставшихся элементов. Программа выводит элементы и очищает очередь. После каждого добавления и извлечения показывается состояние очереди; начало находится слева. Проверки выводятся словами «да» и «нет».
