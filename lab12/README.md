# Лабораторная работа № 12. Работа с очередью

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab12/task01.py
```

Ввод с клавиатуры не требуется. Программа демонстрирует операции с очередью на числах 1, 2, 3. Для другого примера необходимо изменить список в цикле добавления.

Используется `collections.deque` из стандартной библиотеки Python; установка дополнительных пакетов не требуется. После добавления извлекается число 1, в начале остаётся 2, размер равен 2. В конце очередь очищается.

## Версия на JavaScript

В `task01.js` приведены только алгоритмы для сравнения с Python: без ввода, вывода и автоматического запуска.

## Перечень задач

| № | Файл | Задача |
| --- | --- | --- |
| 1 | [task01.py](task01.py), [task01.js](task01.js) | Создание очереди, добавление, извлечение, просмотр, проверка пустоты и размера, поиск, перебор и очистка |

В JavaScript для наглядности используется массив: `push` добавляет в конец, `shift` извлекает из начала. Извлечение через `shift` имеет сложность O(n), в отличие от O(1) у `deque.popleft()` в Python.
