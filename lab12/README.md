# Лабораторная работа № 12. Работа с очередью

## Как запустить

Для запуска необходимо открыть терминал в папке `python-labs` и выполнить:

```bash
python3 lab12/task01.py
```

Введите целые числа через пробел, например `5 10 15`. Программа добавит их в очередь в порядке ввода и продемонстрирует операции с ней.

Используется `collections.deque` из стандартной библиотеки Python; установка дополнительных пакетов не требуется.

Для демонстрации введите `10 20 30`, затем для поиска — `20`.
Программа покажет исходную очередь, первый элемент 10, удалит его и покажет остаток `[20, 30]` и размер 2. Затем найдёт число 20, переберёт оставшиеся элементы без удаления и очистит очередь. Начало очереди находится слева. При пустом вводе программа сообщит, что очередь пуста, и завершится.
